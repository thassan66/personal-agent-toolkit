# Legal and privacy notes

This repository was exported with neutral branding and without bundling the mirrored upstream stub tree.
That reduces obvious trademark/copyright exposure, but it does **not** guarantee zero legal risk.

Recommended precautions before publishing:

1. Keep neutral naming and avoid implying affiliation.
2. Do not publish third-party source code unless the license clearly allows it.
3. Keep attribution and license files for code you do include.
4. Remove any real personal data, tokens, logs, or transcripts.
5. If you later add analytics, hosted APIs, or user data collection, publish a privacy notice.

This is practical publishing hygiene, not legal advice.

# Docs assets

This folder contains public-facing documentation assets for the repository.

## Suggested demo assets

- `demo-startup.gif`
- `demo-workflow-memory.gif`
- `demo-editing.gif`

You can record these with:

- terminal screen capture tools
- asciinema + GIF conversion
- OBS
- ScreenToGif
